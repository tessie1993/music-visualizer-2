Clean-room decisions

What changed before visual design begins

These are structural hypotheses, not a final visual direction. They can be revised without losing the source-derived feature inventory below.

1

Sound source is explicit

Local track, microphone, and other-app capture are peers at the top of Now instead of being scattered between quick actions and Settings.

2

Rendering belongs to Studio

“New render” is a primary Studio action. Settings stores defaults only; it no longer hides the main door into export.

3

Settings uses drill-down pages

An index scales better than six horizontally scrolling tabs and gives each long settings domain a stable back destination.

4

Visual controls are grouped

Long parameter pages use named expandable groups. The full control set remains present without presenting every slider as one unbroken wall.

5

Search is global

Because it already returns tracks, playlists and presets, Search is treated as an app-level overlay rather than as a Library-only utility.

6

System UI stays visibly external

Permissions, file pickers, capture consent, wallpaper setup and share sheets are shown as Android handoffs rather than falsely designed as app screens.
